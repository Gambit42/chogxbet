# Chog Conviction

Minimal Next.js project with TypeScript, Tailwind CSS v4, and shadcn/ui (Base UI). The homepage is blank.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

Reusable UI components live in `src/components/ui`. Theme tokens live in `src/app/globals.css`.
